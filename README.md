# Daksh — Portfolio

A lightweight, responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Before publishing

Replace:
- `YOUR_EMAIL@example.com`
- GitHub URL
- LinkedIn URL

Also update project links when the projects are publicly available.

## Deploy

This can be deployed directly to GitHub Pages, Vercel, Netlify or any static host.
