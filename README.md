# Daksh | Personal Portfolio

Hey, I'm Daksh 👋

I'm a Computer Science and Engineering student at Lovely Professional University, working toward becoming a strong software and cloud/platform engineer.

This repository contains the source code for my personal portfolio website, built to showcase my projects, technical interests, learning journey, and future goals in software engineering and open source.

## 🌐 About the Website

I built this portfolio to create my own space on the internet where I can share what I'm learning, document projects, and connect with developers and potential collaborators.

The website features:

- **Introduction:** Who I am and what I'm working toward.
- **About Me:** My interests in software development, cloud infrastructure, and platform engineering.
- **Projects:** A showcase of my projects and ideas.
- **Tech Stack:** Technologies I'm learning and exploring.
- **My Journey:** My progress toward cloud engineering and open-source contributions.
- **Education:** My Computer Science and Engineering background.
- **Contact:** Links to connect with me professionally.

## 🛠️ Built With

- **HTML5** — Website structure and content.
- **CSS3** — Styling, responsive layouts, animations, and visual design.
- **JavaScript** — Interactive elements and scroll-based reveal animations.
The website uses a lightweight, framework-free approach, making it easy to understand, maintain, and update as my skills grow.
